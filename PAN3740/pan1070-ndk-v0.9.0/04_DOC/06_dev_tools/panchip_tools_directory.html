Panchip 工具目录工具¶

Panchip Tools Directory 是 Shanghai Panchip Microelectronics Co.,Ltd. 为 PAN107x/PAN101x SDK 提供的开发工具集合，目前包含如下功能：

  • PANCHIP 对外提供的所有工具目录工具

  • 可以通过工具目录直接打开下载对于的工具

下载工具。

工具界面¶

工具界面¶

​ 首页为显示 PANCHIP 系列工具目录列表。

​ 目录列表的每一行对应一个系列的工具。

​ 工具系列名: 工具系列包含的工具说明

通用系列工具列表界面¶

​ 点击首页 General Tools 系列工具列表行时，进入通用系列工具列表界面。

​ 目录列表的每一行对应一个工具。

​ 工具名: 工具功能说明。

​ 点击工具列表项时

​ 1、如果工具目录下的 panchip_tools 目录无对应工具，则会先自动下载工具到 panchip_tools 目录中对应的工具名称文件夹，下载成功会自动打开工具运行。

​ 2、如果工具目录下的 panchip_tools 目录已存在对应工具文件，则会自动打开工具运行。

帮助¶

详细使用说明，可以点击软件菜单的 帮助->查看帮助文档。
