PAN107x 低功耗蓝牙功耗分析工具¶

PAN107x 低功耗蓝牙功耗分析工具是 Shanghai Panchip Microelectronics Co.,Ltd. 为 PAN10xx SDK 提供的开发工具集合，目前包含如下功能：

  • 计算分析 PAN107x 低功耗蓝牙功耗分析功能。

下载

工具运行如下图所示。x.x.xxx：为版本号。

芯片设置¶

​ 芯片 : 设置芯片型号选择。目前支持 PAN108x (1M Flash), PAN108x (512K Flash) ，PAN107x

​ SDK 版本 : SDK 版本。默认不可选。

​ 电压 : 设置电压，单位 V. 目前支持 3.3V

​ DCDC 调节器 : 设置 DCDC 或 LDO 选择， on ：为 DCDC，off：为 LDO.

​ 低频时钟 : 为设置低频时钟源。Internal RC: 为内部 RC 时钟；External crystal: 为外部晶振。

​ 无线发送共享 : 为设置无线发射功率值。当前只支持 0 dbm。

蓝牙设置¶

​ 蓝牙设置角色支持 Advertising (TX/RX)、Advertising (TX only)、Connection (peripheral)、Connection (central) 四种模式。

计算功耗¶

​ 设置完芯片设置以及蓝牙设置配置之后，点击计算功耗，则会计算出功耗信息以及绘制不同阶段的功耗图显示。

帮助¶

​ 详情请参考工具Help->Viewing the Help Document查看具体功能介绍。
