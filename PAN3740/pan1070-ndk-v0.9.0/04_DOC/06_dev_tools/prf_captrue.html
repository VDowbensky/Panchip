2.4G 抓包工具¶

Panchip RF Packet Captrue Tool 是 Shanghai Panchip Microelectronics Co.,Ltd. 为 PAN107x/PAN101x SDK 提供的开发工具集合，目前包含如下功能：

  • 配合 PAN107x 芯片 2.4G 抓包模块，抓取周围环境 2.4G 对应协议的空中包

  • 支持抓包的包类型： xn297、nrf、b250k、ble 、nrf52 等协议类型包。

下载工具。

1.功能界面¶

抓包工具界面¶

1、PAN107x 芯片 2.4G 抓包模块需要预先下载射频抓包固件。可以通过工具的帮助->下载 PAN10xx 射频抓包固件，从服务器下载最新版本的射频抓包固件。

2、通过编辑->设置配置，打开配置界面设置抓包协议。

编辑菜单¶

设置 2.4G 抓包配置¶

3、首先需要打开连接，与 2.4G 抓包模块建立连接。

4、可以通过设置过滤，过滤只显示指定频率范围、以及信号强度、以及指定头部数据的数据包显示。

5、开始抓包
