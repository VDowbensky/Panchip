# Panchip DFU 工具

​    专为支持 PANCHIP 芯片鼠标项目开发的 通用DFU升级工具。




## 更新说明

### PanchipDFUTool V0.1.012

​    1、修改芯片平台 PAN108x NDK 改为 PAN10xx NDK。

​    2、修复 PAN10xx NDK 程序载入校验，不进行 HASH 校验。

​    3、修改 PAN10xx NDK DFU 流程前必须先进入强制升级模式。

​    4、升级导出的 exe 程序到 (017) 版本，修改 PAN10xx NDK DFU 流程前必须先进入强制升级模式。



### PanchipDFUTool V0.1.013

​    1、修复 PAN10xx NDK DFU 成功，没有退出强制升级模式问题。



### PanchipDFUTool V0.1.014

​    1、修复 PanchipDFUTool V0.1.012 之后，误改了 PAN108x NDK 1.2.0 版本载入传出设备程序，出现的加载透传设置程序闪退 bug。



### PanchipDFUTool V0.1.015

​    1、修改 PAN10xx NDK DFU 流程。

​    2、调整芯片平台列表显示。
