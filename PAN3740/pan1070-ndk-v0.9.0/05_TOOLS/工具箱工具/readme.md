# PANCHIP 工具箱工具

​    为支持 PAN107x应用测试相关功能工具。

​    打开工具，选择 PAN107x/PAN101x 进入 Panchip ToolBox PAN107x/PAN101x 功能界面。

## 查看帮助文档

​    通过工具的**帮助**->**查看帮助文档**
