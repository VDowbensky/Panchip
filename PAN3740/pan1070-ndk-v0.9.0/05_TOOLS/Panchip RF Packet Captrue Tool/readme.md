# Panchip RF Packet Captrue Tool 工具

​    为支持 2.4G， xn297、nrf、b250k、ble、nrf52 等协议的抓包功能。

​    需要配合 PAN107x USB 射频模块，下载 PAN107x 射频抓包固件的模块使用。

​    通过 PAN107x 射频模块抓取对于协议的包数据，解析包数据信息到工具显示。
