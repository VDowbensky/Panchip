# PAN1070 NDK Feature 说明

#### 开发套件介绍

本项目是 PAN1070 Nimble 开发套件（Development Kit），包含相关的软硬件资料以及使用手册，会持续更新。


#### SDK项目架构
- 01_SDK：PAN1070 NDK 软件开发包，基于开源 OS FreeRTOS 和 BLE协议栈 Nimble 等框架
- 02_HDK: PAN1070 硬件参考设计，开发板的相应图纸等
- 03_MCU: PAN1070 底层外设 Sample 工程
- 04_DOC：PAN1070 相关的文档
- 05_TOOLS: 项目相关的工具，包括量产烧录工具，RF 测试固件等
